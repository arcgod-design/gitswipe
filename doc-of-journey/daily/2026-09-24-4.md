# 2026-09-24 (session 4) — WEEK-03: discovery engine

## What was built

- `packages/discovery` (new package):
  - `candidate.ts` — Candidate model + classification (open fresh = EXISTING_ISSUE, open untouched >90d = STALE_ISSUE; the other 6 kinds from contract §9.1 join via the same `OpportunityKind` union as their engines land), clarity heuristic (body length + welcoming labels), staleness in days, archived-repo filter.
  - `swipes.ts` — `JsonlSwipeStore` (zod-validated against the §9.3 action vocabulary) + why-not reason helpers.
  - `skills.ts` — SkillGraph v0: language weights seeded from history, updated by swipes (right/work/save +3, left −1, why-not −2, wrong-stack → rejectedLanguages → zero match). Deterministic only; framed as learned-from-activity, never objective skill.
  - `rank.ts` — `rankFeed`: score = skill-match 45% + clarity 25% + freshness 20% + saved-similarity 10%; every card carries structured `RankingReason[]`; below-threshold → whyNot with `showAnyway: true`; diversity caps per language (3) and per repo (2) push overflow to whyNot with an explicit "feed diversity cap reached" reason; swiped keys never reappear.
  - `feed.ts` — `FeedCard`/`FeedPage` zod schemas (card contract §9.2) + builders.
- Tests: 11 discovery tests including the exit-test scenario (right-swipe: card excluded, language dominance increases relative to others, next top same language).

## Bugs the tests caught

1. First version of the exit test had a bad premise — with an empty graph all candidates tie and array order wins. Lesson recorded: never assert tie-breaks; seed dominant weights for deterministic scenarios.
2. `.filter()` without `.length` in two diversity assertions (TypeError in toBeLessThanOrEqual).
