## Bugs the tests caught (all fixed same session)

1. `server.listen(0)` port read before bind → providers pointed at port 0; the all-500 failover test passed for the WRONG reason (fetch-fail ≡ aggregate 500 error). Fixed harness (await listen) + hardened assertion (`HTTP 500` in attempt errors) so lucky passes can't recur.
2. Provider `timeoutMs` only governed streams — chat had a hardcoded 30s cap. Found by the hanging-endpoint exit test. Fix: `min(timeoutMs, 30s)` for non-stream calls.
3. DPAPI needs `Add-Type -AssemblyName System.Security` in PS 5.1.
4. My own regex-edit pass corrupted UTF-8 (§ → A) — rule recorded: never bulk-regex-edit non-ASCII via PS 5.1.
