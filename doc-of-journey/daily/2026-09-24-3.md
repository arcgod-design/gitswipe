# 2026-09-24 (session 3) — WEEK-02: GitHub client, PAT auth, entities, ingestion, revalidation

## What was built

- **ADR 0006** — GitHub auth for v1: fine-grained PAT in the OS secret store (per-repo scope = actual least privilege for a local-first tool; zero infrastructure). OAuth device flow / GitHub App stay behind the `GitHubAuth` interface for later.
- `packages/github`:
  - `client.ts` — `GitHubClient`: Link-header pagination (`paginate`), conditional requests (If-None-Match → 304 notModified), backoff on 429/5xx honoring Retry-After then X-RateLimit-Reset (capped 5s), rate-budget tracking exposed after every call, typed error mapping (401→AUTH_FAILURE, exhausted-403/429→RATE_LIMITED, 404→GITHUB_STATE_CHANGED, network→NETWORK_FAILURE).
  - `auth.ts` — `TokenGitHubAuth` (os-store `github:token` > env `GITHUB_TOKEN` dev-flagged > none) + `GitHubAuth` interface.
  - `entities.ts` — zod schemas: NormalizedRepository (health snapshot fields: language, topics, stars, open_issues, archived, license_spdx, pushed_at), NormalizedIssue (+ stale computed at normalize time), NormalizedPullRequest; `normalizeIssue` separates PRs that GitHub mixes into the issues endpoint; draft/merged_at preserved.
  - `store.ts` — `JsonlCandidateStore`: append, upsert (preserves `first_seen_at`, bumps `last_sync_at`), atomic tmp+rename writes.
  - `ingest.ts` — `fetchRepository`, `ingestIssues`/`ingestPullRequests` (async generators over pages), `ingestRepoIntoStore` (counts issues/PRs/stale), `checkIssueState` (open/closed/not_found/permission_denied).
- `@jarvis/daemon`: `github check` command — token presence (masked), `/user`, login + rate budget; honest no-token failure with the exact fix command.
- `.env.example`: GITHUB_TOKEN documented as dev-only fallback.

## Bugs the tests caught

1. Candidate-store `upsert` replaced the whole record, wiping `first_seen_at` — data-history loss. Fixed: upsert preserves first_seen, bumps last_sync (test now asserts both).
2. `normalizeIssue` dropped PR `draft`/`merged_at` fields (hardcoded false/null) — fixed by passing through raw fields.
