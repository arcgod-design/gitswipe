## Bugs the live test caught (all fixed)

1. Static file serving was AFTER auth — the pairing screen couldn't load without a token. Moved BEFORE auth.
2. Session creation route (POST /api/session) was inside the `/api/session/:id` regex block — the regex requires an ID, so the create route was unreachable. Moved outside as a separate check.
3. Static file path resolved to `apps/apps/daemon/public` — the workstation server is one directory deeper than the mvp demo-server. Fixed: `../../public` not `../../../apps/daemon/public`.
4. `git show` piping added UTF-8 BOMs to all 10 cherry-picked files — vite's font loader choked on the BOM in package.json. Fixed with a BOM scan-and-strip.
5. Root package.json lost the `build:web` and `demo` scripts (overwritten during a session). Restored.
