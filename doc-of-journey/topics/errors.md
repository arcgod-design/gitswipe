# topics/errors.md — append-only error catalog

> Rule: any error costing >5 minutes gets an entry. Grep this file BEFORE debugging anything.

## 2026-09-24

- **PS 5.1 `Set-Content -Encoding utf8` writes BOMs into JSON** — npm/tsc tolerate them, tsx's package.json parser does not (`Error parsing: apps/daemon/package.json` from tsx `getPackageType`). Fix: rewrite with `[System.IO.File]::WriteAllText($path, $text, [UTF8Encoding]::new($false))`. Cost ~20 min including diagnosis. Any future .json written via PowerShell needs the no-BOM write.
- **npm 10.2 arborist crash `Cannot read properties of null (reading 'edgesOut')`** when installing vitest@4 (optional-peer graph triggers a bug in `#loadPeerSet`). vitest@5.0.1 resolves cleanly and is the patched line for GHSA-82fw-gwwq-j7x9. Fix: jump vitest 3 → 5 directly; do not attempt 4. Cost ~15 min.
- **`npm run <script> -- --flag`**: npm eats recognized flags (`--version`, `--check`) even after `--`. Fix: positional subcommands in CLIs (`npm run daemon -- check`), keep flags for direct invocation only. Cost ~10 min.
- **node:http mock server with SSE**: `server.close()` hangs forever unless the handler calls `res.end()` AND teardown calls `server.closeAllConnections()`. Symptom: vitest afterEach hook timeout 10000ms cascading across unrelated tests. Cost ~10 min.
- **`server.listen(0)` is async** — reading `server.address()` synchronously after returns null/port 0; providers pointed at port 0 and every call "fetch failed". Worse: the failover all-500 test PASSED for the wrong reason (fetch-fail produced the same aggregate error as real 500s). Await the listen callback, and make error-assertions specific (e.g. assert `HTTP 500` in attempt errors) so lucky passes can't happen. Cost ~15 min.
- **DPAPI in PowerShell 5.1 needs `Add-Type -AssemblyName System.Security`** before `[Security.Cryptography.ProtectedData]` exists — otherwise "Command failed". Cost ~10 min.
- **PS 5.1 Get-Content/Set-Content regex round-trips corrupt UTF-8** — a bulk `Get-Content -Raw` + `-replace` + `Set-Content` pass mangled non-ASCII in test titles (§ became A, em-dashes broke). Rule: never bulk-regex-edit files containing non-ASCII via PS 5.1; use the write tool, rewrite whole files, or keep code/titles ASCII-safe. Cost ~10 min.
- **Provider `timeoutMs` only applied to streams** — chat calls had a hardcoded 30s cap, so a provider configured with `timeoutMs: 150` hung for 30s. Found by the WEEK-01 exit test (hanging-endpoint test hit vitest's own 5s timeout). Fix: `longRunning ? timeoutMs : Math.min(timeoutMs, 30_000)`. Cost ~10 min.
- **Undeclared workspace dependency (brutal audit, 2026-09-24)**: dev's @jarvis/daemon imported zod without declaring it - worked only via npm hoisting from sibling packages; the mvp branch had it declared but the fix never landed on dev after branch divergence. Rule: after any branch diverges, dep-audit both (imports vs declared deps) before merging. Fixed + hoisting-proof.
- **JARVIS_DATA_DIR operator footgun (brutal battery, 2026-09-24)**: CLI (jarvisd pair) and serve silently used different data dirs when env discipline slips - the battery's first pairing 401'd with both sides 'working'. Config is per-process by design (s116), but the CLI must SHOW which data dir it touches: pair and devices list now print data dir: ... so mismatches are visible in one glance.
- **Same spec violation escaped twice across ports (2026-09-24, WEEK-06)**: the mock agent skipped RUNNING -> TESTING -> REVIEW_READY -> COMPLETED and jumped straight to COMPLETED - the protocol state machine caught it BOTH in the mvp demo (session 8) AND again in the fresh packages/agents port (session 11). Lesson: agent timelines are contract-s19 state machine citizens; any new agent adapter MUST be tested against the full transition table, and porting a timeline means re-reading the state diagram, not reusing memory.
- **CI-environment-dependent tests (2026-09-24, CI runs 24/25)**: gate tests passed on Windows but failed on CI because the scratch repo lacked a LOCAL git identity - the beforeEach used per-command -c flags for setup commits, but the gate-executed 'git commit' ran without them and died with exit 128 ('Please tell me who you are'). Rule: any test that executes real git through a component must configure identity in the fixture repo itself ('git config user.name/email' after init), never rely on global config. Also: secret-scanner-safe fixtures - build fake tokens from fragment joins so no format-valid literal ships in source (GitHub flagged the redaction test's dummy AIza... key as a public leak).
- (also: write tool rejects raw-JSON content params — write .json via PowerShell, see tactics)

- **Static files served AFTER auth (WEEK-08, 2026-10-01)**: the pairing screen IS the entry point - it must load without a token. Static file serving must come BEFORE the device-token auth check, or the UI 401s and users can never pair. Cost ~15 min.
- **Session creation route unreachable (WEEK-08, 2026-10-01)**: POST /api/session was inside the /api/session/:id regex block. The regex requires an ID segment, so bare POST /api/session never matched. Rule: routes with and without path params must be separate checks (the no-param check BEFORE the regex). Cost ~10 min.
- **Static file path off by one directory level (WEEK-08, 2026-10-01)**: workstation/server.ts is one level deeper than mvp's demo-server.ts (workstation/ subdir). The relative path resolved to a double-nested apps/apps/... path. Rule: when copying a static-path pattern between files at different depths, recount the ../ levels - and prefer testing GET / right after wiring, not last. Cost ~10 min.
- **git show piping adds UTF-8 BOMs (WEEK-08, 2026-10-01)**: extracting 10 files from the mvp branch via git show mvp:path in PowerShell silently added BOMs to every file. vite's font loader choked on the BOM inside package.json. Rule: after ANY git show extraction, scan and strip BOMs (check bytes EF BB BF). Cost ~15 min.
- **Root package.json script loss (WEEK-08, 2026-10-01)**: build:web and demo scripts were lost during a prior session's package.json rewrite. No test catches missing npm scripts (vitest runs directly). Rule: after any package.json overwrite, diff the scripts block against the previous version. Cost ~5 min.
- **Reasoning models burn hidden tokens before visible content (2026-10-04, hit TWICE)**: nemotron-3-super returned EMPTY chat replies with maxTokens 20 and maxTokens 100 - all budget went to reasoning. 300 tokens works ('OK' reply). Rule: test pings / short structured calls against reasoning models get maxTokens >= 300, and empty-content-with-usage-reported means 'raise the budget', not 'parse bug'. Cost ~20 min across both hits.
- **Daemon default dataDir is ./data, not .data (2026-10-04)**: a smoke script assumed join(cwd,'.data') and got 'no key in store' while the key sat in ./data/secrets. Same JARVIS_DATA_DIR footgun as before, new variant: when writing one-off scripts that touch the store, import dataDir() logic from the daemon or pass JARVIS_DATA_DIR explicitly. Cost ~10 min.
- **Global search-replace collateral (2026-10-04)**: replacing className="pair-input" across App.tsx to introduce .form-input also hit PairScreen's pairing-code input, whose uppercase mono style is INTENTIONAL. Rule: scope class-name replacements to the component being edited, or use distinct class names from day one (pairing = .pair-input, forms = .form-input - now locked in styles.css). Cost ~5 min.
- **Android Studio SDK Manager 'Not in GZIP format' (2026-10-04, hit 3x)**: the IDE downloader fetches packages over plain HTTP (dl.google.com) and the network mangled the zips - repeated retries always failed the same way, while OTHER packages from the same host succeeded. Fix: download the package zip MANUALLY over HTTPS (curl), Expand-Archive, move into Sdk/<slot>. cmdline-tools now lives at cmdline-tools/latest and runs. Rule: when a package manager's downloader fails repeatedly with format errors, bypass it and fetch the artifact yourself over HTTPS. Cost ~30 min.
- **Move-Item into an existing directory NESTS instead of replacing (2026-10-04)**: the SDK Manager retry re-created cmdline-tools/latest with a .installer marker, so Move-Item put the extracted tree one level too deep (latest/cmdline-tools/...). Then deleting latest to redo the move destroyed the already-moved content (Move is not Copy). Fix: re-extract from the still-present zip. Rule: before Move-Item into a destination that may exist, Test-Path it; when in doubt Copy-Item then Remove-Item. Cost ~5 min.
- **PowerShell -> .bat argument semicolons split (2026-10-04)**: & .bat --install "build-tools;37.0.0" reached cmd.exe split into two args ('build-tools not found, 37.0.0 not found'). Known PS-to-cmd quoting hazard. Not worth fighting - build-tools 34/35 were already intact and sufficient. Cost ~3 min (correctly abandoned).
- **Manually-installed SDK packages are invisible to Android Studio without package.xml (2026-10-04)**: moving an extracted package zip into Sdk/<slot> leaves only source.properties; the IDE and sdkmanager then read the local version as 'unknown' and the SDK Manager shows it not-installed. Fix: copy a working package.xml from an installed sibling, reuse its <license> block verbatim, swap the <localPackage> record (path/version/display-name). Verified: cmdline-tools/latest flipped from 'unknown -> 23.0.0' to '23.0.0' and the IDE needs only a restart. Cost ~20 min.
