# topics/errors.md — append-only error catalog

> Rule: any error costing >5 minutes gets an entry. Grep this file BEFORE debugging anything.

## 2026-09-24

- **PS 5.1 `Set-Content -Encoding utf8` writes BOMs into JSON** — npm/tsc tolerate them, tsx's package.json parser does not (`Error parsing: apps/daemon/package.json` from tsx `getPackageType`). Fix: rewrite with `[System.IO.File]::WriteAllText($path, $text, [UTF8Encoding]::new($false))`. Cost ~20 min including diagnosis. Any future .json written via PowerShell needs the no-BOM write.
- **npm 10.2 arborist crash `Cannot read properties of null (reading 'edgesOut')`** when installing vitest@4 (optional-peer graph triggers a bug in `#loadPeerSet`). vitest@5.0.1 resolves cleanly and is the patched line for GHSA-82fw-gwwq-j7x9. Fix: jump vitest 3 → 5 directly; do not attempt 4. Cost ~15 min.
- **`npm run <script> -- --flag`**: npm eats recognized flags (`--version`, `--check`) even after `--`. Fix: positional subcommands in CLIs (`npm run daemon -- check`), keep flags for direct invocation only. Cost ~10 min.
- **node:http mock server with SSE**: `server.close()` hangs forever unless the handler calls `res.end()` AND teardown calls `server.closeAllConnections()`. Symptom: vitest afterEach hook timeout 10000ms cascading across unrelated tests. Cost ~10 min.
- **`server.listen(0)` is async** — reading `server.address()` synchronously after returns null/port 0; providers pointed at port 0 and every call "fetch failed". Worse: the failover all-500 test PASSED for the wrong reason (fetch-fail produced the same aggregate error as real 500s). Await the listen callback, and make error-assertions specific (e.g. assert `HTTP 500` in attempt errors) so lucky passes can't happen. Cost ~15 min.
- **DPAPI in PowerShell 5.1 needs `Add-Type -AssemblyName System.Security`** before `[Security.Cryptography.ProtectedData]` exists — otherwise "Command failed". Cost ~10 min.
- **PS 5.1 Get-Content/Set-Content regex round-trips corrupt UTF-8** — a bulk `Get-Content -Raw` + `-replace` + `Set-Content` pass mangled non-ASCII in test titles (§ became A, em-dashes broke). Rule: never bulk-regex-edit files containing non-ASCII via PS 5.1; use the write tool, rewrite whole files, or keep code/titles ASCII-safe. Cost ~10 min.
- **Provider `timeoutMs` only applied to streams** — chat calls had a hardcoded 30s cap, so a provider configured with `timeoutMs: 150` hung for 30s. Found by the WEEK-01 exit test (hanging-endpoint test hit vitest's own 5s timeout). Fix: `longRunning ? timeoutMs : Math.min(timeoutMs, 30_000)`. Cost ~10 min.
- **Undeclared workspace dependency (brutal audit, 2026-09-24)**: dev's @jarvis/daemon imported zod without declaring it - worked only via npm hoisting from sibling packages; the mvp branch had it declared but the fix never landed on dev after branch divergence. Rule: after any branch diverges, dep-audit both (imports vs declared deps) before merging. Fixed + hoisting-proof.
- **JARVIS_DATA_DIR operator footgun (brutal battery, 2026-09-24)**: CLI (jarvisd pair) and serve silently used different data dirs when env discipline slips - the battery's first pairing 401'd with both sides 'working'. Config is per-process by design (s116), but the CLI must SHOW which data dir it touches: pair and devices list now print data dir: ... so mismatches are visible in one glance.
- (also: write tool rejects raw-JSON content params — write .json via PowerShell, see tactics)
